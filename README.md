# Financial Performance Dashboard: Superstore Sales Analysis

## Overview
Developed an ETL pipeline and Power BI dashboard to analyze Superstore’s financial performance, using MySQL, Python (Pandas, NumPy, Matplotlib), and Excel to deliver actionable insights for optimizing sales and profit strategies.

## Skills Demonstrated
- ETL (MySQL/Pandas)
- EDA (MySQL/NumPy)
- Data visualization (Power BI/Matplotlib)
- Stakeholder communication
- Business intelligence

## Process
- Extracted and transformed sales/profit data from a MySQL database, addressing missing values and inconsistencies.
- Performed EDA to uncover trends, such as Technology’s 50.79% sales share ($145.45k) and Central’s low 13.86% profit.
- Built an interactive Power BI dashboard with slicers, visualizing sales by region, category, and monthly trends (e.g., 2015 decline, 2016 recovery).

## Key Findings
- Technology led sales at 50.79% ($145.45k), while Furniture lagged at 6.44% ($18.45k).
- West region contributed 37.86% of profit ($108.42k), with Central at 13.86%.
- Sales/profit declined in 2015, recovering in 2016, indicating market fluctuations.

## Impact
The dashboard reduced reporting time by 15% (estimated) and enabled stakeholders to address underperforming areas like Furniture and Central, demonstrating business intelligence value.

## Tools
MySQL, Power BI, Python (Pandas, NumPy, Matplotlib), Excel.
